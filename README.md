## Installation
1. Download the library as a zip file.
2. Unzip the file and copy it to the Arduino library folder (normally in Documents/Arduino/libraries).
3. Reopen the Arduino IDE and open the example in File -> Examples -> raspberry-arduino-serial -> raspberry-arduino-serial.ino

## The example demonstrates how to use the library which creates a serial communication between Raspberry pi and Arduino and configures a 16kHz PWM signal on pins 3, 9, 10, and 11.
