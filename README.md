## Installation
1. Download the library as .Zip file.
2. Unzip the file and copy it to Arduino libary folder (noramlly in Documents/Arduino/libraries).
3. Reopen the Arduino IDE and open the example in File -> Examples -> raspberry-arduino-serial -> raspberry-arduino-serial.ino

## The example demonstrate how to use the library which creats a serial communication between Raspberry pi and Arduino and configures 16kHz PWM signal on pin 3, 9, 10, and 11.
